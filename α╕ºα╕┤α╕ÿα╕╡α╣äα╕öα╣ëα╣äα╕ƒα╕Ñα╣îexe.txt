วิธีได้ PostureShimeji.exe (ดับเบิลคลิกแล้วขึ้นเลย ไม่ต้องลง Python)
==================================================================

ทำครั้งเดียว ประมาณ 10-15 นาที (ส่วนใหญ่รอเฉยๆ)

1. สมัคร/ล็อกอิน https://github.com (ฟรี)
2. กด + มุมขวาบน -> New repository -> ตั้งชื่ออะไรก็ได้ เช่น posture -> Create repository
3. กด "uploading an existing file" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง
   (ต้องรวมโฟลเดอร์ .github ด้วย ถ้าลากไม่ติด ให้ใช้ GitHub Desktop แทน)
   -> กด Commit changes
4. ไปแท็บ Actions -> เลือก "Build Windows exe" -> Run workflow -> รอ ~10 นาทีจนขึ้นติ๊กเขียว
5. กลับหน้าแรกของ repo -> ด้านขวามี "Releases" -> กดเข้าไป -> ดาวน์โหลด PostureShimeji.exe
6. ก๊อปไฟล์ exe ไปไว้ที่ไหนก็ได้ ดับเบิลคลิกใช้ได้เลย

หมายเหตุ
- เปิดครั้งแรกอาจรอ 10-30 วินาที (ไฟล์ใหญ่ ต้องแตกตัวเอง) ครั้งต่อไปก็ช้าเท่าเดิม
- Windows SmartScreen อาจเตือน -> กด More info -> Run anyway
- ถ้ามีเครื่อง Windows ที่ลง Python 3.11 อยู่แล้ว ดับเบิลคลิก build.bat ก็ได้ exe เหมือนกัน (อยู่ใน dist\)
